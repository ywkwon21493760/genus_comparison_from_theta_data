# Fast theta-cache directory

This directory is used by the experiment scripts for cached SageMath/NumPy
artifacts.

Small catalog files may be tracked in GitHub:

- `id_catalog_4_4000.npz`
- `ood_catalog_4001_8000.npz`

Large theta-coefficient matrices are not tracked in the regular GitHub
repository because of file-size limits:

- `id_theta_MAXP600.npy`
- `ood_theta_MAXP600.npy`

These `.npy` files can be regenerated by running the experiment scripts, or
included in the archived Zenodo release for convenience.
